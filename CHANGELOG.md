# Changelog

## 0.2.0
- **Ajuda e conteúdo didático:** menu "Como usar" (guia passo a passo, glossário com 50+ termos, explicação do método com exemplo numérico calculado pelo próprio núcleo, boas práticas e FAQ, calculadora de amostras) e página "Sobre, créditos e privacidade".
- **Rodapé completo** (aprender, sistema, fontes de dados, acessibilidade, créditos, aviso de uso).
- **Domínio:** % de distribuição por componente (confere com a Tabela 2 da monografia), indicadores metalúrgicos (recuperação, razão de enriquecimento, razão de concentração, rendimento), análise de redundância/observabilidade, unidades por campanha.
- **Produtividade:** colar dados da planilha, exportar CSV para Excel pt-BR, números no formato brasileiro, aceitação de vírgula/ponto decimal.
- **Conta:** troca de senha pelo próprio usuário.
- Mascote com novas dicas; migração Alembic 0002; novos testes (68 no total).

## 0.1.0
- Núcleo de cálculo (mínimos quadrados com restrições, Gauss), API REST, interface web, banco, integrações IBGE e Open-Meteo, catálogo ANM, VLibras, mascote de dicas.
- Área `/admin`, CSRF, bloqueio de login, auditoria, identidade visual em PNG fixo, migração Alembic 0001.
