Como funciona o método

{% include "ajuda/_nav.html" %}

Entre todos os conjuntos de valores que fecham o balanço, o {{ brand.name }} escolhe o que menos se afasta das medidas, levando em conta a confiança de cada uma. Esta página mostra como, com números reais do exemplo da monografia.

1. O problema, com um exemplo

Circuito de finos da Carbonífera Cambuí: um ciclone (fluxo 1 entra; 2 e 3 saem) seguido de uma espiral (fluxo 3 entra; 4, 5 e 6 saem). Valores medidos, em t/h:

Com os dados medidos, o ciclone não fecha: entra {{ ex.rows[0].x|num(2) }} e sai {{ (ex.rows[1].x + ex.rows[2].x)|num(2) }}. O resíduo é {{ ex.antes_op1|num(2) }} no ciclone e {{ ex.antes_op2|num(2) }} na espiral. Depois do ajuste, os resíduos são {{ ex.depois_op1|num(6) }} e {{ ex.depois_op2|num(6) }}: zero, a menos de arredondamento.

Repare no fluxo 3: foi de {{ ex.rows[2].x|num(2) }} para {{ ex.rows[2].xa|num(2) }}. As medidas ao redor dele (1 e 2 na entrada do ciclone; 4, 5 e 6 nas saídas da espiral) apontam para um valor bem menor, e o ajuste divide a diferença entre as medidas conforme a confiança de cada uma. Uma correção desse tamanho é o que o sistema sinaliza como medida suspeita: vale voltar à amostragem desse ponto.

2. Passo a passo

Passo 1 · O fluxograma vira uma matriz M

Uma linha por operação, uma coluna por fluxo: +1 se o fluxo entra na operação, −1 se sai, 0 se não se liga. O balanço de massas fecha quando M · vazões = 0.

             fluxo: 1   2   3   4   5   6
Ciclone          [ +1  −1  −1   0   0   0 ]
Espiral          [  0   0  +1  −1  −1  −1 ]

Passo 2 · Cada medida ganha um peso

O peso é 1/σ². Medida precisa (σ pequeno) tem peso grande e quase não muda; medida duvidosa tem peso pequeno e absorve a correção. Para um fluxo não amostrado, σ = valor: confiança mínima.

Passo 3 · O que se minimiza

minimizar   F = Σ ( x̂ⱼ − xⱼ )² / σⱼ²        sujeito a   M · x̂ = 0

Em palavras: a soma dos quadrados das correções, cada uma medida em unidades da sua própria incerteza, sob a condição de que todas as operações fechem.

Passo 4 · Multiplicadores de Lagrange

Para impor as restrições na minimização, acrescenta-se um multiplicador λ por operação. Derivando, o problema vira um sistema linear de (m + n) equações, com m fluxos e n operações:

[ 2P   Mᵀ ] [ x̂ ]   [ 2P·x ]
[  M    0 ] [ λ  ] = [   0  ]          com P = diag(1/σ²)

Os valores de λ são só um artifício matemático e não têm significado de processo.

Passo 5 · Eliminação de Gauss

O sistema é resolvido por eliminação de Gauss com escolha do melhor pivô: triangulariza a matriz e resolve de trás para frente. Se algum pivô for nulo, o sistema é indeterminado ou inconsistente e o cálculo é interrompido com um aviso.

Passo 6 · Balanço de um componente (teor)

Para um teor, a quantidade que se conserva é vazão × teor. Como é um produto, usa-se a vazão já ajustada como constante e ajusta-se c = vazão × teor (com σ de c = vazão × σ do teor); depois, teor ajustado = c ajustado ÷ vazão. No exemplo, o teor de cinzas ajustado fica em {{ ex.cinzas_alim|num(2) }}% na alimentação e {{ ex.cinzas_conc|num(2) }}% no concentrado (fluxo 6).

Passo 7 · Testes de qualidade

  • Teste global (χ²): compara o resíduo de fechamento com o que o erro aleatório esperado explicaria. No exemplo, χ² = {{ ex.chi2|num(2) }} com {{ ex.dof }} graus de liberdade (limite de 95% ≈ 5,99).
  • Resíduo normalizado (z): quanto cada medida foi corrigida, em unidades da sua incerteza. |z| > 1,96 chama atenção.

3. Redundância: de onde vem o poder de correção

Medir mais do que o estritamente necessário é o que permite corrigir erros. Se você mede todos os 6 fluxos do exemplo e há 2 equações, sobram 2 equações para ajustar as medidas (redundância 2). Se deixa de medir o fluxo 3, ele é calculado a partir dos demais e ainda sobra 1. Se deixa de medir os fluxos 1 e 2 ao mesmo tempo, o balanço do ciclone não os distingue (indeterminados). A página de cada campanha mostra essa análise.

4. Limitações que você deve conhecer

  • O ajuste é linear e não impõe valores positivos: ele avisa, mas pode devolver vazão negativa.
  • Assume que os erros são independentes entre medidas e que a usina esteve estável durante a coleta.
  • O balanço de teores usa as vazões já ajustadas como se fossem exatas; a incerteza delas não se propaga para os teores.
  • Com fluxos não amostrados tratados por σ grande, o teste χ² é aproximado.
  • O sistema aponta suspeitas, mas não descobre sozinho a causa de um erro grosseiro; isso depende do seu conhecimento da usina.
